# CustomShellNew (CSNew)

**Менеджер меню «Создать» и категорий приложений в «Пуске» Windows 11**

## Возможности

В программе три вкладки: **Меню «Создать»**, **Пуск** и **Резервные копии**.

### Меню «Создать»

- **Все пункты в одном списке**: и обычные типы файлов, и пункты, добавленные приложениями из Microsoft Store (например, Paint).
- **Показать / скрыть** любой пункт переключателем «В меню».
- **Порядок пунктов**: перемещайте вверх и вниз, справа виден предпросмотр в том порядке, в котором пункты появятся в Проводнике.
- **Добавление новых типов файлов**: расширение, название, шаблон и значок.
- **Редактирование** названия, шаблона и значка существующих пунктов.
- **Удаление** пунктов. Перед удалением из реестра автоматически создаётся резервная копия.
- **Закрепление меню**: Проводник перестаёт перезаписывать ваш порядок и набор пунктов.
- **Поиск и фильтры** по списку.
- **Сброс настроек** и **перезапуск Проводника** одной кнопкой.

### Пуск

Настройка категорий в разделе «Все» меню «Пуск» (режим «По категориям»).

- **Доска категорий**: каждая категория — отдельная карточка со списком приложений, значки берутся у самой Windows.
- **Перетаскивание мышью** приложений между категориями, можно сразу несколько (`Ctrl` / `Shift`).
- **Контекстное меню** «Переместить в…» как альтернатива перетаскиванию.
- **Поиск** по названию приложения или ключу реестра, в подсказке и строке состояния видно текущий номер `Category`.
- **Разгруппировать**: записать `Category = 0` для всех приложений, они окажутся в «Другое».
- **Найти удалённые**: поиск записей приложений, которых уже нет в системе, с подтверждением удаления для каждой записи. Запись считается удалённой, только если приложения нет в списке «Пуска» и при этом не установлен пакет Store или не найден файл классической программы. Всё сомнительное остаётся нетронутым.
- **Откатить из копии**: перед первым изменением за сеанс программа сохраняет копию категорий всех приложений, последнюю копию можно восстановить одной кнопкой.
- **Перезапуск Проводника**, чтобы «Пуск» подхватил изменения.
- Права администратора для этой вкладки не нужны.

### Общее

- **Резервные копии** меню «Создать»: восстановление или удаление копий на отдельной вкладке.
- Светлая и тёмная тема, подстраивается под систему.

## Как это работает

### Меню «Создать»

Меню управляется двумя независимыми слоями, и CSNew работает с обоими.

**1. Список Проводника**

```
HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Discardable\PostSetup\ShellNew
```

Значение `Classes` (`REG_MULTI_SZ`) определяет, какие пункты показываются и в каком порядке. Через него управляются *все* пункты, в том числе от Store-приложений.

Проводник сам перезаписывает это значение, поэтому CSNew при включённом закреплении добавляет на ключ запрет `Deny SetValue` для группы `Everyone`. Так же поступает, например, ContextMenuManager. Снять запрет можно в самой программе (выключить закрепление или сбросить настройки).

**2. Ключи `ShellNew` в `HKCR\.расширение`**

Шаблоны, названия, значки, удаление и добавление новых типов. Отключение пункта дополнительно переименовывает ключ `ShellNew` в `ShellNew.disabled`, а включение возвращает имя обратно.

### Пуск

Категория каждого приложения хранится в реестре текущего пользователя:

```
HKCU\Software\Microsoft\Windows\CurrentVersion\Start\TileProperties\<приложение>
```

В подключе приложения лежит значение `Category` (`REG_DWORD`). Ключи бывают вложенными: для Store-приложений они выглядят как `P~Пакет!App`, для классических программ как `W~{GUID}\app.exe`. CSNew читает эти ключи, берёт читаемые названия у `Get-StartApps` и записывает новый номер категории при перетаскивании. После записи программа уведомляет оболочку, но чтобы «Пуск» отобразил изменения, обычно нужно перезапустить Проводник или заново войти в систему.

Приложение попадает в `TileProperties`, когда вы открываете «Пуск» → «Все» в режиме «По категориям». Если список в CSNew пуст, откройте «Пуск» в этом режиме и нажмите «Обновить».

## Установка

### Готовый .exe

Скачайте `CustomShellNew.exe` из раздела [Releases](../../releases) и запустите. Программа запрашивает права администратора, они нужны для записи в реестр при работе с меню «Создать».

### Из исходников

Требуется Windows 11 и Python 3.10+.

```bash
pip install PyQt6 "PyQt6-Fluent-Widgets[full]"
python csnew.py
```

Для полного набора функций запускайте от имени администратора. Без этих прав порядок и скрытие пунктов в меню «Создать» работают, но шаблоны, названия и удаление системных ключей реестра могут не сработать. Вкладка «Пуск» права администратора не требует. В окне есть кнопка «Перезапустить от администратора».

## Сборка .exe

Положите `icon.ico` рядом с `csnew.py` и выполните:

```bash
pip install pyinstaller PyQt6 "PyQt6-Fluent-Widgets[full]"

pyinstaller --noconfirm --clean --onefile --windowed --uac-admin ^
  --name CustomShellNew --icon icon.ico --add-data "icon.ico;." ^
  --collect-all qfluentwidgets csnew.py
```

(для PowerShell замените `^` на `` ` ``, или запишите команду в одну строку)

Результат: `dist\CustomShellNew.exe`.

| Ключ | Зачем |
| --- | --- |
| `--onefile` | один .exe-файл |
| `--windowed` | без консольного окна |
| `--uac-admin` | запрос прав администратора при запуске |
| `--icon icon.ico` | значок самого .exe |
| `--add-data "icon.ico;."` | иконка окна и панели задач внутри .exe |
| `--collect-all qfluentwidgets` | ресурсы и стили библиотеки |

Если антивирус ругается на `--onefile`, замените его на `--onedir`.

В `icon.ico` должны быть размеры 16, 32, 48 и 256 px, иначе значок будет размытым.

## Где хранятся данные

Настройки, шаблоны и резервные копии лежат в `%APPDATA%\CustomShellNew`:

```
%APPDATA%\CustomShellNew\
├── backups\          резервные копии удалённых пунктов меню «Создать» (JSON)
├── start_backups\    копии категорий приложений «Пуска» (JSON)
├── templates\        скопированные шаблоны файлов
└── state.json        порядок и состояние пунктов
```

## Важно

CSNew изменяет реестр Windows. Перед удалением пунктов меню «Создать» и перед первым изменением категорий «Пуска» программа делает резервную копию, но перед серьёзными экспериментами имеет смысл создать точку восстановления системы.

Если после изменений меню «Создать» не обновилось, нажмите «Перезапустить Проводник». Проводник держит список в памяти. То же относится к «Пуску»: новые категории появятся после перезапуска Проводника или повторного входа в систему.

Номера категорий «Пуска» в Windows не документированы и могут измениться в будущих обновлениях системы.
